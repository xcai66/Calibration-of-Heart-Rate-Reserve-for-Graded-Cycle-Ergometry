# Public data provenance and licenses

## Graded Incremental Test Data

- Creators: Bernard Donne, Neil Fleming, Garry Campbell, Tomás Ward, David Crampton, and Nick Mahony.
- Record: https://doi.org/10.5281/zenodo.10841412
- Version used: 2.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0).
- Local source archive: `data_v2_clean.zip`.
- Role: candidate-sport comparison, cycling model development, and temporal validation.
- Modification: the local archive is a clean copy of the public version used for extraction. Derived CSV files were generated by `03_code/01_extract_graded_tests.py`.

Required attribution:

Donne B, Fleming N, Campbell G, Ward T, Crampton D, Mahony N. Graded Incremental Test Data (Cycling, Running, Kayaking, Rowing): an open access dataset. Version 2. Zenodo; 2024. doi:10.5281/zenodo.10841412.

## ACTES

- Creators: Clovis Chabert, Denis Mongin, Eric Hermand, Aurélie Collado, and Olivier Hue.
- Record: https://doi.org/10.13026/2qs3-kh43
- Version used: 1.0.0.
- License: PhysioNet Open Data Commons Attribution License v1.0.
- Local files: `actes_test_measure.csv`, `actes_subject-info.csv`, and `actes_LICENSE.txt`.
- Role: independent external validation.
- Modification: RR intervals were converted to HR and aggregated with VO2 and power into non-overlapping 10-second active bins by `03_code/03_validate_selected.py`.

Required attribution:

Chabert C, Mongin D, Hermand E, Collado A, Hue O. Cardiorespiratory measurement from graded cycloergometer exercise testing. Version 1.0.0. PhysioNet; 2022. doi:10.13026/2qs3-kh43.
